MakerMind AI 不是「再生成一份教案」，而是输出学生任务卡、材料清单、课堂流程、代码思路与融会贯通训练——老师拿到就能进教室。

我们解决什么问题？

很多老师认同项目式学习，但备课成本高：要把知识点、学生兴趣、硬件条件和课堂时长拼成一套可执行方案，往往要花一整个下午。

  • 输入：知识点 + 兴趣场景 + 硬件/时长
  • 输出：完整 STEAM 项目任务包，不是泛泛的教案文字
  • 闭环：生成 → 布置 → 课堂记录 → 反馈（教师端工作台）

和普通 AI 备课工具有什么不同？

维度 普通 AI 教案 MakerMind AI
输出形态 文字教案、习题建议 任务卡 + 材料清单 + 步骤 + 代码 + 融会贯通
课堂可执行性 老师还要自己拆任务、估时间 按 15 / 45 / 60 分钟档位直接可用
硬件整合 很少涉及具体套件 K10 / Arduino / micro:bit / 纯软件多档匹配
稳定性 一次长生成，易失败 overview / build / practice 三段生成 + 失败重试

评委可能关心的技术点

三段式 AI 生成

拆成概述、制作实践、融会贯通三段独立请求，降低 token 压力，单段失败可重试。

教育向 Prompt

约束输出为 STEAM 项目结构（任务层次、硬件等级、家长可读反馈），不是自由发挥散文。

Serverless 全栈

Cloudflare Workers + D1 数据库 + 静态资源同域部署；密钥不进前端。

TRAE 开发链路

本项目使用 TRAE IDE / Work 迭代，从生成器到教师闭环工作台完整可演示。

愿景与联系

让每一位老师都能在 15 分钟内设计出一节「能体验、能动手、能展示」的项目课。
